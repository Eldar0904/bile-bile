# Биле-биле!

Kazakh-language landing page for a dance-party game concept.

**Live:** https://eldar0904.github.io/bile-bile/

## Local preview

Run `python -m http.server 5173` here, then open http://localhost:5173.

No build step or dependencies. Edit index.html, style.css and app.js directly. GitHub Pages automatically publishes the main branch root.

## Artwork and social assets

- `dance-hero-final.png`: landing-page artwork.
- `socials/bile-bile-final.png`: square feed poster.
- `socials/bile-bile-story.png`: vertical Stories/Reels cover.
- `socials/caption-kk.txt`: suggested Kazakh caption.

The visual direction uses the original vivid orange/cobalt/magenta/lime palette and dance streetwear: bomber jackets, cargo trousers and sneakers. The girls wear plain loose inner T-shirts covering their midriffs without chest contouring. Kazakh influence stays subtle.

Artwork created and edited using built-in image generation. Final prompts preserve the dance composition and streetwear, use loose flat-front inner tops, cover midriffs, and keep the exact Kazakh campaign text. Story layout adapts the approved square poster to 9:16 with text safe areas.

This page presents a concept, not a playable game. No song catalogue, scoring, sign-up backend or social posting is implemented.
