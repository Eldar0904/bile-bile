# Биле-биле!

Kazakh-language landing page for a dance-party game concept.

Live site: https://eldar0904.github.io/bile-bile/

## Local preview

Run `python -m http.server 5173` in this directory, then open http://localhost:5173.

No build step or dependencies. Edit index.html, style.css and app.js directly. GitHub Pages publishes the main branch root.

## Artwork

Dancer artwork uses lightweight, loose, fully covered dancewear with Kazakh-inspired details. Generated with built-in image generation. Social campaign image is in socials/.

The page presents a concept, not a playable game. No song catalogue, scoring or sign-up backend is implemented.
